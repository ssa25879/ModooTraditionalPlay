# 시작 지점에서 문 앞으로 이동하기.

대상 씬은 `Assets/Scenes/main_playoursound.unity`입니다. 씬 배치와 Inspector 연결은 프로젝트 지침에 따라 사용자가 수행합니다. `DoorTeleport`는 씬을 전환하지 않고 현재 씬 안에서 XR Origin을 이동합니다. 기존 문의 `DoorSceneTransition`은 그대로 유지합니다.

## 씬 구성.

1. XR Origin의 `Teleportation Provider`를 찾습니다. 해당 Provider의 `Locomotion Mediator`와 `XR Body Transformer`가 현재 XR Origin에 연결되어 있어야 합니다. 즉시 이동하려면 Provider의 `Delay Time`을 `0`으로 설정합니다.
2. 각 콘텐츠 문 앞에 빈 오브젝트를 만들고 `장구_문앞_도착점`, `사방치기_문앞_도착점`처럼 이름을 붙입니다. 문과 겹치지 않는 바닥 위치에 놓고, 파란색 Z축이 문을 향하도록 Y 회전을 조정합니다. 도착점의 높이는 머리 높이가 아닌 발이 닿는 바닥 높이입니다.
3. 플레이어 시작 지점에서 가리키기 쉬운 위치에 콘텐츠별 Cube 또는 안내판을 배치합니다. Collider와 `DoorTeleport`를 추가합니다. `XRSimpleInteractable`은 자동으로 추가됩니다. 안내 문구는 `장구 문 앞으로 이동`, `사방치기 문 앞으로 이동`처럼 구분합니다.
4. 각 `DoorTeleport`의 `Teleportation Provider`에 1번의 Provider를, `Destination`에 대응하는 도착점을 연결합니다.
5. `Left Controller`, `Right Controller`에는 기존 문의 `DoorSceneTransition`에서 사용하는 양손 Ray 또는 Near-Far Interactor를 연결합니다. 컨트롤러 루트 Transform을 넣는 필드가 아닙니다.
6. `XRSimpleInteractable`의 `Colliders`와 `Interaction Layer Mask`를 확인합니다. 양손 Interactor의 Interaction Layer Mask와 겹쳐야 하며, Collider의 GameObject Layer도 컨트롤러의 Raycast Mask에 포함되어야 합니다. 기존 문의 설정을 참고하면 됩니다.
7. Interactor의 `Activate Input`은 기존처럼 해당 손의 트리거에 연결합니다. A 버튼은 스크립트가 `<XRController>{RightHand}/primaryButton` 입력을 사용하므로 기존 공용 Input Actions를 수정할 필요가 없습니다. 오른손 A에 대응하는 primaryButton을 제공하는 XR 컨트롤러가 필요합니다.

텔레포트 오브젝트에는 `DoorSceneTransition`을 함께 붙이지 않습니다. `Teleportation Anchor` 또는 `Teleportation Area`를 같은 오브젝트에 붙이면 별도 입력으로 이동 요청이 중복될 수 있으므로 `XRSimpleInteractable`과 `DoorTeleport`를 사용합니다.

## 확인할 동작.

- 왼손 또는 오른손으로 이동 오브젝트를 가리키고 해당 손의 트리거를 누르면 대응하는 문 앞에 도착합니다.
- 오른손으로 가리키고 A 버튼을 누르면 이동합니다. 왼손만 가리키고 오른손 A를 누르면 이동하지 않습니다.
- 아무것도 가리키지 않고 트리거/A를 누르면 이동하지 않습니다.
- 버튼을 계속 누르고 있거나 누른 상태로 다른 이동 오브젝트를 가리켜도 이동이 반복되지 않습니다. 놓았다가 다시 눌러야 합니다.
- 오른손 트리거와 A를 동시에 눌러도 한 번만 이동 요청을 보냅니다.
- 도착하면 문을 바라봅니다. 실제 HMD의 수평 위치 오프셋은 XRI Provider가 처리합니다. 머리 높이와 지면 충돌 여부는 실기기로 확인합니다.
- 도착한 문을 다시 가리키고 트리거를 눌렀을 때 기존 콘텐츠 씬 전환이 동작하는지 확인합니다.

이 가이드는 배치 지침입니다. 코드 컴파일 확인과 Play Mode/실기기 확인은 별개이며, Inspector를 연결하기 전에는 이동 동작을 검증할 수 없습니다.
